# LocalBox 本地工具箱 V1.0 产品需求文档（PRD）
> 产品名称：LocalBox
> 仓库名称：local-box-toolkit
> 产品定位：一站式本地工具平台，Web / Electron电脑端 / 安卓端。全部运算本地执行，文件不上传服务器，包含格式转换、开发工具、证件照、便民工具。支持浅色/深色/跟随系统三主题，无广告，基础功能无次数限制。

## 1. 文档概述
### 1.1 文档目的
本文档为 LocalBox V1.0 产品需求文档，定义产品定位、用户群体、功能需求、交互规范、性能指标、禁止需求，作为产品设计、开发、测试依据。

### 1.2 产品定位
LocalBox 本地工具箱，是**纯本地运算**的多端工具集合，支持 Web网页端、Windows/Mac电脑客户端（Electron）、安卓APP。
所有文件处理、数据生成逻辑在用户设备本地完成，**文件不上传任何服务器**。
覆盖办公文档格式转换、Office转图片、图片处理、开发人员常用生成工具、证件照制作、日常便民小工具。
支持浅色 / 深色 / 跟随系统三种主题，无广告，基础功能无次数、文件大小限制。

### 1.3 用户群体
1. 办公用户：Word/Excel/PDF格式转换、文档转图片、证件照制作
2. 开发人员：UUID生成、MD5/SHA、Base64、时间戳转换等
3. 普通用户：图片压缩、格式转换、单位换算等便民工具

### 1.4 终端范围
Web端、Electron电脑端、安卓APP；V1.0暂不支持iOS。

## 2. 竞品分析
### 2.1 竞品优点
1. UuTool：工具种类丰富，网页端打开即用，基础功能免注册。
2. EveryTool：优先本地浏览器运算，保护用户隐私，无弹窗广告。
3. Convertio：支持数百种格式互转，文档转换兼容性强。
4. Visafoto：内置各国证件照标准尺寸，人脸检测、背景替换能力成熟。

### 2.2 竞品缺点
1. 大多只提供Web网页，缺少桌面客户端、安卓APP，移动端网页适配差，不支持离线。
2. 功能碎片化，格式转换、证件照、开发工具分散在不同网站，需要切换多个平台。
3. 很多工具云端处理文件，存在文档泄露风险。
4. 批量转换、高清导出、Office转图片等功能，大多收费或者限制次数。
5. 缺少完整三主题切换方案；部分工具广告多，弹窗干扰。
6. 缺少完整的 Office直接转图片能力，很多仅支持PDF转图片，Word/Excel转图容易排版错乱。

### 2.3 LocalBox差异化优势
1. 三端一体：Web、电脑客户端、安卓APP一套工具集，支持离线使用。
2. 全部本地运算：文件不上传服务器，保护隐私。
3. 一站式聚合：文档转换、Office转图片、图片处理、开发工具、证件照、便民工具集成。
4. 纯净体验：无任何广告，批量转换、高清300DPI导出全部免费开放。
5. 三主题支持：浅色、深色、跟随系统自动切换。
6. 本地持久化：工具收藏、操作历史、配置参数保存在本机，无需服务端。

## 3. 功能需求
> 所有工具三端功能保持一致，仅交互适配屏幕差异。

### 3.1 全品类格式转换模块
#### 3.1.1 Office文档互转
支持输入：docx、doc、xlsx、xls、pptx、ppt、pdf、txt
支持转换组合：
1. Word(docx) → PDF / TXT
2. PDF → TXT
3. Excel(xlsx) → PDF
4. PPT(pptx) → PDF
5. TXT → PDF
6. PDF专项工具：PDF合并、PDF拆分、PDF压缩、PDF去水印

> 备注：旧二进制格式 doc / xls / ppt 前端本地解析兼容性有限，界面增加兼容性提示。
> 支持单文件、批量文件处理；批量结果打包ZIP下载。

#### 3.1.2 Office/PDF转图片（核心功能）
输入文件：docx、xlsx、pptx、pdf
输出图片格式：JPG、PNG、WEBP、TIFF
可配置参数：
1. DPI：72 / 150 / 300DPI
2. 色彩模式：彩色 / 灰度黑白
3. 导出模式：分页导出（每页独立图片） / 纵向长图合并
4. 页码范围：自定义起始页、结束页
5. 图片质量：0~100%可调

功能要求：
- 转换前预览页面缩略图
- Word保留段落、表格、内嵌图片；Excel保留单元格边框；PPT还原幻灯片页面
- 批量多文档处理，结果打包ZIP
- 大于50页文档，提示内存占用风险，支持后台任务处理

#### 3.1.3 图片格式转换
支持互转：JPG、PNG、WEBP、GIF、BMP、SVG
配套功能：图片无损压缩、分辨率自定义修改、EXIF信息清除、保留透明背景；支持批量。

#### 3.1.4 音视频格式转换
底层FFmpeg WASM本地处理
支持视频：MP4、AVI、MOV、FLV、MKV
支持音频：MP3、WAV、FLAC
功能：视频压缩、音频提取，支持批量处理。

### 3.2 开发工具模块（纯本地计算，无网络请求）
1. UUID生成器：UUID v1/v3/v4/v5；自定义数量1~10000条、自定义命名空间；单条复制，批量导出TXT；本地保存历史记录。
2. Base64编码 / 解码
3. URL编码 / 解码
4. MD5、SHA1、SHA256哈希计算
5. 时间戳与日期时间互转
6. 随机密码生成
7. 二维码、条形码本地生成

### 3.3 证件照 & 图片处理模块
1. 内置尺寸：一寸、二寸、小二寸、身份证、护照、各国签证照标准尺寸。
2. 能力：人脸检测、智能抠图、背景替换（白色/蓝色/红色），Canvas本地渲染。
3. 输出：300DPI高清图片，本地导出无水印。
4. 基础图片编辑：裁剪、缩放、旋转、图片模糊、添加文字、添加水印、去除底色。

### 3.4 便民工具模块（纯前端计算）
单位换算、时间换算、颜色取色器、批量文件重命名、文本去空格/去换行、字数统计、图片EXIF清除。

### 3.5 本地存储功能（无后端）
存储内容保存在当前设备本地，**不跨设备自动同步**：
1. 主题设置
2. 工具收藏列表
3. 操作历史记录
4. 用户常用工具参数配置

存储介质：
- Web端：IndexedDB + localStorage
- Electron电脑端：本地JSON配置文件（AppData目录）
- 安卓端：uni-app本地存储API

> 可选扩展（V1不做）：支持手动导出/导入备份文件，实现跨设备迁移。

## 4. 三端适配需求
### 4.1 Web端
- 浏览器兼容：Chrome90+、Edge90+、Firefox88+
- 宽屏自适应布局，最小宽度1200px
- 支持拖拽上传文件、多选批量上传
- 大文件处理提示内存占用风险

### 4.2 Electron电脑客户端（Windows / Mac）
- 完全离线可用，无网络也可使用全部工具
- 读取本地系统文件，支持拖拽导入
- 支持后台异步任务处理大文档
- 可选桌面快捷方式

### 4.3 安卓APP
- 最低支持 Android 9.0
- 竖屏优先布局，触控按钮放大，避免点击盲区
- 读取手机相册与本地文件
- APK安装包体积 ≤30M

## 5. UI主题需求
> 支持三种主题：浅色模式（默认）、深色模式、跟随系统。
> 整体风格：现代极简商务风，干净克制，无花哨渐变。
> 切换主题时全局色值一键替换，CSS变量驱动。

### 5.1 浅色主题（白天办公，白底淡灰）
| 用途 | 色值 | 视觉描述 |
|---|---|---|
| 页面背景 | `#F5F7FA` | 淡淡的冷灰白，比纯白柔和，带轻微蓝调 |
| 卡片/弹窗背景 | `#FFFFFF` | 纯白色 |
| 主文字 | `#1D2129` | 墨黑色，比纯黑柔和，长时间阅读不刺眼 |
| 次要文字 | `#6E7681` | 中灰色，用于提示文字、占位符 |
| 边框分割线 | `#E5E6EB` | 极浅灰细线，弱存在感 |
| 主题主色 | `#1677FF` | 明亮科技蓝天蓝色，主按钮、选中态高亮 |
| 主色浅背景 | `#E8F3FF` | 极淡浅蓝色，hover、选中项背景 |
| 成功色 | `#00B42A` | 鲜亮草绿色，成功提示 |
| 警告色 | `#FF7D00` | 橘橙色，警告提示 |
| 错误色 | `#F53F3F` | 正红色，错误、删除操作 |
| 卡片阴影 | `rgba(0,0,0,0.08)` | 极淡阴影，营造卡片悬浮感 |

### 5.2 深色主题（夜间护眼，深炭黑底）
| 用途 | 色值 | 视觉描述 |
|---|---|---|
| 页面背景 | `#17171A` | 深炭黑色，不是死纯黑 |
| 卡片/弹窗背景 | `#232324` | 比页面背景浅一档的深灰 |
| 主文字 | `#F2F3F5` | 柔和近白色 |
| 次要文字 | `#86909C` | 灰蓝色，用于辅助说明文字 |
| 边框分割线 | `#2E2E30` | 深灰细线 |
| 主题主色 | `#4096FF` | 亮天蓝色，深色下更醒目 |
| 主色浅背景 | `#192945` | 深藏蓝色，hover、选中背景 |
| 成功色 | `#00C48C` | 青薄荷绿 |
| 警告色 | `#FF9500` | 琥珀橙 |
| 错误色 | `#FF4D4F` | 亮红色 |
| 卡片阴影 | `rgba(0,0,0,0.3)` | 深色下较明显阴影 |

### 5.3 跟随系统逻辑
1. 监听操作系统明暗模式，系统浅色自动切浅色主题；系统深色自动切深色主题。
2. 设备无法读取系统主题时，默认降级为浅色模式。

### 5.4 通用UI规范
- 圆角：卡片8px、按钮6px、弹窗12px
- 字体：中文 PingFang SC / Microsoft YaHei；英文、数字 Inter
- 动画：弹窗、主题切换动画时长200ms缓动

## 6. 性能指标
1. 页面启动响应 ≤0.5秒
2. 10页docx文档，300DPI转图片耗时 ≤5秒
3. 批量100条UUID生成瞬时完成
4. 应用崩溃率 ≤0.1%
5. 所有基础功能无使用次数限制，无文件大小限制

## 7. 隐私安全需求
1. 全部运算在本地设备执行，文件不上传任何服务器。
2. 处理完成自动清理临时缓存文件。
3. 安卓APP仅申请存储权限，不申请多余隐私权限。
4. 不收集用户个人信息。

## 8. 禁止需求
1. 禁止增加弹窗广告、开屏广告、信息流广告。
2. 禁止对批量转换、高清导出等基础功能设置付费锁。
3. 禁止强制注册登录才能使用基础工具。
4. 禁止后台静默上传用户文件、用户生成数据。
5. 禁止三端功能阉割，移动端保持完整工具能力。

## 9. V1.0 上线验收清单
1. 三套主题切换（浅色 / 深色 / 跟随系统），完整CSS变量色值体系
2. Office文档互转、PDF工具集（本地Wasm）
3. Office/PDF转图片，支持DPI、分页/长图、批量打包下载
4. 图片、音视频本地格式转换（FFmpeg WASM）
5. UUID、哈希、编码解码全套开发工具，本地运算
6. 证件照制作 + Canvas图片编辑工具
7. 全套便民工具
8. 本地存储：主题配置、工具收藏、历史记录
9. Web、Electron、安卓三端全部离线可用
10. 纯净无广告，基础功能无次数限制
